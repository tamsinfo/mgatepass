# Material Gatepass Management System

Internal application for managing material gatepasses across organizational units. Handles the creation, approval, tracking and closure of gatepasses for materials entering or leaving premises.

## Tech Stack

- **Backend:** SAP Cloud Application Programming Model (CAP) on Node.js
- **Frontend:** SAP UI5
- **Database:** SAP HANA Cloud
- **Deployment:** SAP BTP Cloud Foundry

## Development

```bash
bun install
cds watch
```
